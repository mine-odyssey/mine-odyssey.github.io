# Mine Odyssey

Benchmarking Spatial Agentic Intelligence in the Wild.

Project website: https://mine-odyssey.github.io/

Paper: [arXiv:2610.11328](https://arxiv.org/abs/2610.11328) · [PDF](https://arxiv.org/pdf/2610.11328)

Authors: Yuxuan Cao, Junlong Li, Hao Li, Junxian He.

Code: [hkust-nlp/MineOdyssey](https://github.com/hkust-nlp/MineOdyssey)
