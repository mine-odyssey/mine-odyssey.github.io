下载 Windows 连接助手

Windows 10/11（Intel/AMD 64 位）：先“全部解压缩”，再双击 Connect Mine Odyssey.bat。macOS：解压后运行连接助手。评测时保持连接窗口打开。

  1. 安装 Prism Launcher，登录自己的 Microsoft / Minecraft Java 账号。
  2. 准备任务后，下载专用客户端包，在 Prism 中选择“添加实例 → 导入”。Windows 和 macOS 均导入此包，由启动器安装对应系统的依赖。
  3. 启动该实例，在“多人游戏 → 直接连接”输入下面的服务器地址。
  4. 游戏显示等待界面后，回到本页点击“开始任务”。
每项任务使用新下载的实例，以保持地图探索状态一致。不要添加额外模组。断开游戏连接会结束当前尝试。
